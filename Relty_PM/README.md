# Relty PM 产品资料库

本目录集中维护 Relty 健身模块的产品侧资料，包括 PRD、指标设计、需求草案，以及会直接影响产品承诺边界的研究材料。

## 目录

### `01_PRD/`

- `健身模块产品文档.md`：模块定位、MVP 闭环、识别优先级与 Fitness Balance 设计。
- `训练报告需求草案.md`：训练完成质量、燃脂、心肺、节奏与恢复等报告需求草案。

### `02_指标设计/`

- `PAI指标计算方式.md`：PAI 指标的输入、归一化与计算说明。
- `全天活动识别算法设计规格说明书.md`：全天活动识别的产品目标、信号输入与算法规格。

### `03_产品研究/`

- `运动训练健康评估指标_DeepResearch.md`：消费级运动健康评估指标研究。
- `Ego_IMU健身动作识别技术边界研究.md`：胸前相机与 IMU 的能力边界及产品承诺建议。

## 维护规则

1. 新增或修改产品文档时，同步更新 `CHANGELOG.md`。
2. 每条变更写明日期、文件、变更类型和产品影响。
3. 产品定义与技术实现分开维护；API、代码流程和实验结果仍保留在研发目录。
4. 未定结论应明确标注“待确认”，避免草案被误当作正式口径。
