# PAI 指标计算方式

PAI（Personal Activity Intelligence）是一种基于心率反应的身体活动指标。它的核心思想不是直接统计运动分钟数，而是把用户在活动过程中的心率暴露换算成一个滚动周期内的活动分数。

PAI 更关注“这段活动对该用户造成了多强的心肺刺激”，而不是用户具体做了什么运动。因此，同样 30 分钟活动，对不同年龄、静息心率、最大心率和体能水平的人，可能产生不同的 PAI。

## 1. 输入数据

PAI 计算通常需要以下数据：

- 当前心率序列；
- 静息心率；
- 最大心率；
- 活动持续时间；
- 用户生物计量信息，例如性别、年龄、身高、体重等。

其中，心率数据是核心。用户的静息心率和最大心率用于把绝对心率换算成相对心率强度。

## 2. 心率归一化

首先计算用户的心率范围：

```text
Δy = y_max - y_rest
```

其中：

- `y_max` 表示最大心率；
- `y_rest` 表示静息心率；
- `Δy` 表示该用户从静息到最大心率之间的可用心率范围。

然后将每个时间点的心率换算为归一化强度：

```text
ȳ_k = (y_k - y_rest) / Δy
```

连续形式为：

```text
ȳ(t) = (y(t) - y_rest) / Δy
```

其中：

- `y_k` 表示第 `k` 个采样点的心率；
- `y(t)` 表示连续时间上的心率函数；
- `ȳ_k` 或 `ȳ(t)` 表示该用户在该时刻的相对心率强度。

## 3. 强度评分

PAI 不是线性地给每分钟活动加分，而是使用指数函数放大高强度心率的贡献。

离散形式：

```text
z_k = c1 × (e^(c2 × ȳ_k) - 1)
```

连续形式：

```text
z(t) = c1 × (e^(c2 × ȳ(t)) - 1)
```

其中：

- `z_k` 或 `z(t)` 表示心率强度评分；
- `c1` 是换算系数；
- `c2` 是加权系数；
- `e` 是自然指数函数。

这一步是 PAI 的关键。心率越高，`z` 的增长越快，因此高强度活动比低强度活动更快累积分数。

## 4. 活动评分 P

然后对监测周期内的强度评分进行求和或积分，得到活动评分 `P`。

离散形式：

```text
P = Σ Δt × z_k
```

连续形式：

```text
P = ∫ z(t) dt
```

其中：

- `Δt` 表示采样间隔；
- `P` 表示监测期内的累计心率暴露。

PAI 通常使用滚动周期，例如过去 7 天。也就是说，新的活动会进入窗口，较早的活动会逐渐移出窗口。

## 5. 健康预测活动评分 V

专利中进一步将活动评分 `P` 映射为健康预测活动评分 `V`：

```text
V = c3 + c4 × (1 - e^(-P))
```

其中：

- `c3` 和 `c4` 是由群体研究数据确定的常数；
- 该函数是饱和型函数，意味着活动增加带来的收益不是无限线性增长。

这体现了公共健康研究中的常见现象：从完全不活动到少量活动，边际收益最大；活动量继续增加后，边际收益会逐渐下降。

## 6. PAI 换算

最后将 `V` 换算为 PAI：

```text
PAI = 100 × (V - c3) / (V_threshold - c3)
```

其中：

- `V_threshold` 是根据用户生物计量数据选择的阈值；
- 专利示例中，男性用户阈值可为 `45`，女性用户阈值可为 `35`。

当用户达到对应阈值时，PAI 约为 100。因此，PAI 的常见目标是：

```text
PAI ≥ 100
```

## 7. 专利示例参数

基础专利中给过一个男性用户示例：

```text
c1 = 4.51
c2 = 7.73
c3 = 29.5
c4 = 19.8
V_threshold = 45
```

女性用户的 `V_threshold` 示例为：

```text
V_threshold = 35
```

这些参数是示例值，不应直接理解为所有用户、所有设备和所有产品场景的通用参数。

## 8. 产品使用注意

PAI 的完整商业实现并不等同于公开专利中的简化公式。公开资料说明了计算框架，但不同产品实现可能还有额外的数据清洗、心率质量判断、参数选择和人群校准。

对 Relty AI Pin 而言，如果使用毫米波雷达估计心率，需要特别注意运动场景下的心率准确性风险。毫米波雷达心率可能受到身体晃动、衣物、佩戴角度、环境反射和力量训练屏息等因素影响。

因此，产品中应区分心率可信度：

```text
confirmed intensity：心率信号质量高，可用于中/高强度判定
estimated intensity：心率信号较弱，主要靠 IMU + 活动类型估算
unknown intensity：证据不足，不计入强度分
```

如果没有获得官方授权或完整算法，不建议直接声称“实现官方 PAI”。更稳妥的表述是：

```text
Relty 可以参考 PAI 的心率暴露思想，建立一个 PAI-like 的滚动 7 天心率活动指标。
```
