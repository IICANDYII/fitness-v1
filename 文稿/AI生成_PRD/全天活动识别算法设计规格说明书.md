# 全天活动识别算法设计规格说明书 (Daily Activity Tracking Algorithm Specification)

本说明书针对“胸前单目相机 (1fps) + 胸口 IMU（惯性测量单元）”的穿戴式设备形态，设计了一套低功耗、事件驱动型的全天活动识别与健康指标分析算法。

---

## 1. 算法核心架构

算法整体运行采用“**端侧低功耗滤波监控 + 关键事件触发视觉 + 云端多模态推理**”的分布式管线，最大程度优化设备的电池寿命（目标整机续航 $\ge 18$ 小时），同时保证活动记录的语义准确性。

```
  ┌────────────────────────────────────────────────────────┐
  │                    胸骨端侧设备 (On-Device)             │
  │                                                        │
  │ [50Hz IMU] ──> SMA 滤波与能量估算 ──> 状态分类 (三向分流) │
  └──────────────────────────────────┬─────────────────┬───┘
                                     │ (触发活动改变)   │ (每5分钟轮询)
                                     ▼                 ▼
  ┌────────────────────────────────────────────────────────┐
  │ [1fps 相机] ───────────────> 唤醒单帧抓拍 ───────────────┤
  └──────────────────────────────────┬─────────────────────┘
                                     │ (上传帧 + IMU 特征包)
                                     ▼
  ┌────────────────────────────────────────────────────────┐
  │                    云端大模型 (Cloud Inference)        │
  │                                                        │
  │      [视觉语义分类] + [IMU 动力学特征] ──> 时空交叉对齐   │
  │                                           │
  │                                           ▼
  │                           [Session 划分与健康指标聚合]
  └────────────────────────────────────────────────────────┘
```

## 2. On-Device：本地端侧状态过滤与事件触发器

胸前设备本地微控制器（MCU）持续采集 50Hz 三轴加速度数据，进行窗口大小为 $N=250$（5秒时间窗口，无重叠）的信号幅值面积（Signal Magnitude Area, SMA）和标准差（Standard Deviation, SD）计算：

### 2.1 核心数学公式

*   **三轴重力分量分离 (Gravity Estimation)**：
    由于重力加速度恒定存在（约 1g），必须先分离重力分量 $[g_x, g_y, g_z]$。在端侧通常使用窗口均值（低通滤波效果）估算重力分量：
    $$g_x = \frac{1}{N} \sum_{t=1}^{N} a_x(t), \quad g_y = \frac{1}{N} \sum_{t=1}^{N} a_y(t), \quad g_z = \frac{1}{N} \sum_{t=1}^{N} a_z(t)$$

*   **身体信号幅值面积 (Body SMA)**：
    减去重力分量以提取纯身体运动信号（AC分量），避免重力恒定分量导致静态状态误判（Gravity Leak）：
    $$a_{\text{body}, x}(t) = a_x(t) - g_x, \quad a_{\text{body}, y}(t) = a_y(t) - g_y, \quad a_{\text{body}, z}(t) = a_z(t) - g_z$$
    $$\text{Body SMA} = \frac{1}{N} \sum_{t=1}^{N} \left( |a_{\text{body}, x}(t)| + |a_{\text{body}, y}(t)| + |a_{\text{body}, z}(t)| \right)$$
    *用于估算实际主动运动所消耗的能量代谢（METs）级别。*

*   **三轴合加速度标准差 (SD)**：
    针对原始总加速度大小（Magnitude）计算标准差，用以过滤动态姿态变化：
    $$a_{\text{mag}}(t) = \sqrt{a_x(t)^2 + a_y(t)^2 + a_z(t)^2}$$
    $$\text{SD} = \sqrt{\frac{1}{N} \sum_{t=1}^{N} \left( a_{\text{mag}}(t) - \bar{a}_{\text{mag}} \right)^2}$$
    *用于区分静态稳定性（如办公久坐 vs 睡眠）。*

### 2.2 三向分流判别矩阵

MCU 每 5 秒对当前时间窗的 Body SMA、SD 和重力向量进行评估，判定用户所处的三大基本生理状态：

| 生理状态 | 阈值判定条件 | 本地设备控制行为 |
|:---|:---|:---|
| **A. 睡眠/躺平** | $\text{Body SMA} < 0.05g$ 且 $Y$ 轴重力分量 $|g_y| < 0.2g$ | ① **关闭相机传感器**；<br>② IMU 降低采样至 10Hz；<br>③ 停止向云端发送数据。 |
| **B. 静止/久坐** | $\text{Body SMA} < 0.15g$ 且 $\text{SD} < 0.05g$ | ① **关闭相机传感器**；<br>② 启动日常久坐时间累加；<br>③ 仅在静止时间 $> 30$ 分钟时上传一次心跳包。 |
| **C. 活动状态** | $\text{Body SMA} \ge 0.15g$ 或 $\text{SD} \ge 0.05g$ | ① 启动步态分析；<br>② **根据事件触发机制唤醒相机**；<br>③ 缓存 IMU 特征包准备上传。 |

### 2.3 视觉唤醒与抓拍触发机制

在“**C. 活动状态**”下，相机绝对不进行持续拍摄。仅在满足以下两个条件之一时，触发单帧抓拍（1fps）：

1.  **事件边界触发（Event Boundary Trigger）**：
    当 IMU 动作分类器检测到当前的运动模式（基于滑动窗口波形的主频和幅值）发生突变（例如从“平稳步行”突变为“原地高频起伏”，预示用户从散步进入健身区），立即触发相机拍摄 1 帧。
2.  **时间轮询触发（Periodic Polling）**：
    若用户持续处于某种相同的活动状态，相机每隔 **5分钟** 自动唤醒并拍摄 1 帧，以刷新当前的视觉上下文（如确认用户是否仍在骑车或跑步机上）。

## 3. Cloud：云端多模态特征对齐与事件划分

当设备将抓拍帧（Image）与前后 10 秒的 IMU 特征包（包括步频、重力向量倾角、SMA）上传至云端后，云端运行多模态对齐分类器。

### 3.1 视觉分类器提取环境语义（Context Classification）

云端视觉模型利用 Zero-shot CLIP 或轻量级目标检测模型，将图像映射至以下日常活动环境/互动操纵物中，输出置信度最高的类别：

$$\text{Context} = \text{argmax} \left( \text{CLIP}_{\text{zero-shot}}(\text{Image}, \text{Gym, Office, Road, Car\_Interior, Home}) \right)$$

| 视觉特征点 | 环境语义标签 |
|:---|:---|
| 电脑屏幕、键盘、办公椅、文件柜 | `Deskwork` (办公桌) |
| 方向盘、仪表盘、车窗外高速倒退景物 | `Driving` (驾驶/通勤) |
| 自行车把手、摩托车把手、双侧后视镜 | `Riding` (骑行) |
| 跑步机显示屏、椭圆机拉杆、动感单车把手 | `Cardio_Machine` (有氧器械) |
| 杠铃架、哑铃架、负重器械、橡胶地板 | `Gym_Strength` (力量训练区) |
| 人行道、树木、马路、红绿灯 | `Outdoor` (户外) |

### 3.3 多模态交叉融合决策树

结合 IMU 测量的物理步频（Cadence）与视觉标签，进行最终的活动事件（Activity Session）识别：

```
                              ┌──> [Cadence >= 120] ───────────────> 跑步 (Running)
                              │
               ┌──> 户外 ─────┼──> [60 <= Cadence < 120] ──────────> 步行 (Walking)
               │              │
               │              └──> [Cadence < 60] ─────────────────> 站立闲逛 (Standing)
               │
               ├──> 骑行 ──────────────────────────────────────────> 户外骑行 (Cycling)
               │
环境语义 ──────┼──> 办公桌 ───> [IMU 极静止 SD < 0.03g] ────────────> 办公久坐 (Sedentary)
               │
               ├──> 驾驶 ──────────────────────────────────────────> 乘车/通勤 (Commuting)
               │
               ├──> 有氧器械 ─> [IMU 稳定震动波形] ──────────────────> 室内有氧 (Indoor Cardio)
               │
               └──> 力量区 ───> [IMU 经典推/拉/腿起伏] ──────────────> 力量训练 (Gym Workout)
                                                                         │
                                                                         ▼
                                                               激活 Gym L3/L4 识别管线
```

## 4. 指标聚合算法：每日活动健康画像

算法在每日结束时（用户进入睡眠状态后），将全天识别出的活动事件进行统计聚合，生成符合 WHO 与 AHA LE8 科学规范的数据画像：

### 4.1 每日等效中高强度活动分钟数（MVPA）

依据 AHA Life's Essential 8 标准，高强度活动时间双倍计入有氧分钟数：

$$T_{\text{MVPA\_daily}} = \sum T_{\text{Walking}} + \sum T_{\text{Indoor\_Cardio}} + 2 \times \left( \sum T_{\text{Running}} + \sum T_{\text{Cycling}} \right)$$

有氧得分直接映射至 0-100 分。

### 4.2 力量训练达标度

评估力量训练事件（`Gym Workout`）的频次与质量：
*   **频率**：判定今日是否完成了一次有效力量训练（持续时长 $\ge 20$ 分钟且 Volume Load $> 0$）。
*   **均衡度**：将本周已完成的所有 Gym Workout 动作细类汇总，统计覆盖的六大功能区（推、拉、膝主导、髋主导、小腿、核心）。

### 4.3 每日久坐报警时段

若系统检测到 `Deskwork` (办公桌) 场景下，IMU 持续处于静止状态且 $\text{SD} < 0.03g$ 的时长累计超过 **60分钟**，则自动输出一段“久坐事件日志”，触发端侧微震动或在 APP 端给予活动拉伸引导。

## 6. 可行的技术解决策略（供研发参考）

为了在设备端侧仅使用胸口 IMU 时也能取得良好的动作特征表征，推荐研发侧在训练阶段引入**“跨模态师生联合预训练机制”**：

1.  **多节点特征联合（Teacher）**：
    利用包含手腕、大腿、胸口等多部位传感器的开源健身数据库（如 `MM-Fit` ）。教师网络在训练时同时读取手腕 IMU（捕捉手部轨迹与握姿）和大腿 IMU（捕捉腿部轨迹）。
2.  **胸骨单点映射（Student）**：
    学生网络仅输入胸腔 IMU数据，通过 KL 散度（Kullback-Leibler Divergence）损失函数，逼近教师网络在隐特征空间（Latent Space）中的表征分布。强迫学生网络学会从胸腔的高频共振波形中解耦并“脑补”出肢端的动作模式，从而在推理阶段大幅度提升 L4 动作细类的分类与置信度标定准确率。
