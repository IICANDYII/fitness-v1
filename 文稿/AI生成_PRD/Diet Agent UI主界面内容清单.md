# Diet Agent UI 主界面内容清单

## 1. 页面目标

Diet Agent 主界面需要让用户通过下滑逐步浏览当天饮食状态、目标进展、摄入数据、历史趋势和每餐记录。

页面重点回答两个问题：

```text
今天吃得怎么样？
今天有没有朝目标前进？
```

## 2. 主界面需要展示的内容

### 2.1 Diet Balance 总览

- 今日 Diet Balance 总分
- 今日状态文案
- Balance 相关的简要解释

### 2.2 Goal 概览

- 当前 Goal 名称
- 当前 Goal 完成进度
- Goal 状态
- `View More` 入口

### 2.3 Calories

- 当日摄入热量
- 当日目标热量 / 推荐热量
- 周期摄入情况
- 历史记录
- 历史趋势

### 2.4 三大营养素

- 当日碳水摄入量 / 占比
- 当日蛋白质摄入量 / 占比
- 当日脂肪摄入量 / 占比
- 历史摄入变化
- 历史趋势

### 2.5 Baseline 变化

- 当前饮食状态与用户历史 baseline 的对比
- 近期变化趋势
- 是否比近期习惯更稳定或更偏离

### 2.6 Today's Meals

- 当天所有摄入记录
- 每餐列表
- 正餐 / 零食标识
- 用餐时间
- 每餐热量
- 每餐宏量营养素
- 每餐食物列表
- 编辑入口

## 3. 页面浏览顺序建议

建议主界面按以下顺序组织：

```text
Diet Balance 总览
→ Goal 概览
→ Calories
→ 三大营养素
→ Baseline 变化
→ Today's Meals
```

首屏应展示 Diet Balance 和 Goal 概览；其余模块通过下滑逐步浏览。
